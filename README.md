# AutoParts Online Store

Responsive five-page auto parts website built with HTML, CSS, and Bootstrap for the WEB Technologies midterm.

## Pages

- `index.html` — Home
- `categories.html` — Categories
- `products.html` — Products, filters, cart, and comparison table
- `about.html` — About
- `contact.html` — Contact form

Open `index.html` in a browser. No build step or JavaScript is required; forms use the visitor's email app.
